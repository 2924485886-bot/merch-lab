# Merch Lab · 应援物料实验室

手机优先的本地照片物料预览工具。保留奶油白背景、浅蓝与浅粉点缀。React + TypeScript + Vite + Tailwind CSS + HTML Canvas + Lucide Icons。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

电脑打开终端的 Local 地址（默认 http://localhost:5173）。手机与电脑连接同一 Wi-Fi，在手机 Safari 或 Chrome 打开终端的 Network 地址。体验时保持电脑和开发服务运行；电脑防火墙需允许 Node.js 的局域网连接。

```bash
npm run build
npm run preview
```

## 使用

上传照片 → 在八种物料中选择 → 调整照片、形状与工艺 → 保存 PNG。

- 小卡与明信片：保留亮膜和哑膜。在预览下方切换正面/背面；默认背面是奶油白底、浅蓝与浅粉的均匀小波点。可上传 JPG、PNG、WebP 替换背面，独立拖动、双指缩放、恢复构图；「恢复默认背面」移除自定义背面并恢复波点。正反面图片与构图各自保留。
- 观察反光：切换到「观察反光」后用手指或鼠标拖动。普通编辑模式仍支持单指拖动与双指缩放。展示倾角滑块也可调整水平方向；「角度归零」恢复正面。
- 对比看看：选择左右工艺，两侧共享当前预览面的照片、裁切与角度。拖动任一侧同步改变反光。对比选择不改变编辑页已经选中的工艺；对比后的展示角度会保留用于导出。
- 人生四格：一次选择 1–4 张照片，点选位置后独立调整裁切与缩放，也可只替换某一格。未上传位置使用首页照片。
- 圆形徽章：保留亮面和哑面，以及金属边缘与弧面阴影。彩虹镭射、星光膜、碎玻璃镭射与小卡/明信片烫金暂时隐藏；特殊工艺模块和扩展接口保留，但当前预览、对比与导出均不会启用它们。
- 亚克力挂件：长方形、正方形、圆形使用首页照片；异形需要带真实透明外部区域的 PNG 或 WebP。
- 亚克力立牌：需要透明底人物素材；绘制平滑外沿、底部插接片与独立底座。若首页照片已含有效透明轮廓，可直接使用。

所有文件只在浏览器读取，无上传服务器请求、后端、数据库、注册或付费 AI。异形人物与轮廓作为整体保留，不在固定图片框内裁切；可拖动改变商品展示角度。

每种物料保留独立构图、工艺、装饰、形状与角度。四格各自保存照片和裁切。返回预览墙不丢失调整。更换首页照片会重新初始化本次所有物料状态；刷新或关闭页面会结束当前会话。

## 导出与效果边界

小卡和明信片默认导出 2400 × 1400 的正反面并排 PNG，也可选「仅正面」或「仅背面」。单面与其他物料导出为 1800 × 1800。PNG 包含干净背景、完整物料、边缘、表面反射和阴影，不含网页控件。没有自定义背面时，双面与背面导出自动使用默认波点。编辑预览、对比和 PNG 共用渲染器，保留当前形状、裁切、工艺与展示角度。手机浏览器可能将 PNG 保存到下载文件夹，需要通过系统分享菜单保存到相册。

亮膜与哑膜反光仍是二维屏幕近似。亮膜以移动的集中高光表示镜面反射，哑膜使用宽而弱的漫反射与中性细粒。照片不做亮度、饱和度或色相调色。

透明轮廓在低分辨率 alpha mask 上计算一次，闭合微小断口、保留主要连续主体、填平内部小孔，再简化和平滑外边界。极细结构、孤立碎片或多个互不相连的主体可能被合并或忽略。透明亚克力边、挂孔、插接和底座都是商品效果示意，不是工厂生产文件，也不保证实体结构强度或精确加工尺寸。实际工艺反射仍取决于光源、膜材和实体样品。

亚克力挂件已移除旧的椭圆描边金属环。目前仅绘制亚克力挂孔，界面明确标注金属挂扣素材待补充。`src/materials/hardware.ts` 预留独立透明配件图层：素材 URL、宽高、连接锚点及来源、作者、许可。后续应使用有明确许可、包含真实金属厚度和连接圈的透明底照片素材，锚点与亚克力孔对齐。核实的 [公有领域龙虾扣照片](https://commons.wikimedia.org/wiki/File:Lobsterclasp.jpg) 为带背景 JPEG，本轮未引入。

## 代码组织

- `src/materials/templates.ts`：八种物料配置、照片区域、可用工艺和名称。
- `src/materials/state.ts`：每种物料的裁切、工艺、倾角、形状、四格，以及独立正反面状态和导出范围。
- `src/materials/backs.ts`：本地生成并缓存默认波点背面。
- `src/materials/export.ts`：单面与双面 PNG 组合，复用同一物料渲染器。
- `src/materials/hardware.ts`：带许可信息与连接锚点的独立透明配件素材接口。
- `src/materials/render.ts`：共享等比例裁切、物料绘制器与统一 Canvas 输出。
- `src/materials/finishes.ts`：可复用反射纹理及独立烫金层。
- `src/materials/transparency.ts`：本地文件读取、真实透明区域检测、主要轮廓计算与缩略图缓存。
- `src/materials/acrylic.ts`：规则与异形挂件、立牌主体、连接结构及底座。
- `src/components/MaterialCanvas.tsx`：Canvas 绘制、Pointer Events 拖动、双指缩放和倾角交互。
- `src/components/Editor.tsx`、`Comparison.tsx`：编辑控件与同角度工艺对比。
- `src/App.tsx`：上传入口、页面流转、状态保存和 PNG 下载。

## 本轮验证

本轮检查覆盖 390 × 844 手机宽度下的小卡/明信片正反面切换、JPG/PNG/WebP 背面上传、分别裁切与双指缩放、返回预览墙后的状态保留、默认波点恢复、单面与双面 PNG，以及其余六种物料的预览和导出。PNG 检查读取应用实际生成的 Blob；双指使用合成 Pointer Events。实体手机触摸及实体印刷样品尚未验证。验收记录保存于项目目录外的 `merch-lab-duplex-validation.md`。

## 版本记录与回退

项目通过 Git commit 记录每轮完成的修改，并推送到 GitHub。项目级 `AGENTS.md` 要求代理完成修改与检查后提交和同步；用户手工编辑不会自动上传，需要执行提交和推送。

在 GitHub 仓库的提交历史中可以查看每版改动。需要回退时，可提供目标版本的提交编号；优先以新的回退提交恢复目标状态，保留后续版本与历史记录。推送失败时，本地提交仍然保留，待认证或网络恢复后继续同步。
